05 / Motion

Minimal & Elegant

GSAP · ScrollTrigger · Lenis

Slide-in from side

Headers and section blocks reveal on scroll, drift in from the left or right, fade up to 1.

gsap.from(el, { x: -60, opacity: 0, duration: 1, ease: "power3.out", scrollTrigger: { trigger: el, start: "top 85%", toggleActions: "play none none reverse" }, });

Alternating L/R

Principle rows alternate alignment; each animates in from its aligned side at x: ±80, opacity 0 → 1.

gsap.from(article, { x: isRight ? 80 : -80, opacity: 0, duration: 1, ease: "power3.out", });

Scroll-tied parallax

Hero content lifts and fades as the user scrolls past it. Scrub-tied — moves with the scrollbar, never on its own.

gsap.to(contentRef.current, { y: -100, opacity: 0, scrollTrigger: { trigger: section, start: "top top", end: "bottom top", scrub: 1 }, });

Hover micro-interactions

200ms Tailwind transitions. Border + text shift to accent. Optional chevron rotates 45° in 400ms.

transition-all duration-200 hover:border-accent hover:text-accent group-hover:rotate-45

Text effects

Scramble on hover (0.6s), split-flap reveal (mechanical), parallax highlight inside Bebas headlines.

<ScrambleTextOnHover duration={0.6}/> <SplitFlapText speed={80}/> <HighlightText parallaxSpeed={0.6}/>

Ambient layers

Lenis smooths page scroll. Noise + grid stay still — they are texture, not motion.

<SmoothScrollAttach /> // lenis .noise-overlay { opacity: 0.03; } .grid-bg { 60px cells }
